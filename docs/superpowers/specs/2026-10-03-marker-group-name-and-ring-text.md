# 集合名称与聚焦环绕文字

## 已确认的需求

- 浏览模式聚焦集合时，沿用模糊标点现有的圆形环绕文字显示效果，内容为集合名称。
- 集合编辑栏可修改集合名称，并预留日文和英文名称；当前界面语言决定显示哪一个名称，未填写时回退到另一语言或旧名称。
- 集合编辑栏提供与模糊标点一致的「文字距离中心」和「文字旋转角度」控制，每个集合独立保存。
- 新集合默认使用现有全局模糊标点的文字参数。
- 集合名称也进入现有翻译扫描流程，改动扫描和全库扫描都覆盖集合名称。
- 不迁移或批量改写现有伞记录；旧 `markerGroupName` 继续作为没有新名称时的兼容回退。

## 实现方式

把双语集合名及两项环绕文字参数存放在 `data/site-settings.json` 每组 `markerGroups` 配置里。共享纯函数负责清理/更新名称与参数，并由前端和本地 API 共用。聚焦集合时调用原有圆形标签组件，按集合独立参数绘制；集合编辑栏实时预览并自动保存。翻译扫描器额外读取 `site-settings.json` 中的集合名称。

## 验收

- 自动测试覆盖：名称双语清理与回退、每组文字参数隔离/边界、名称缺英文可被翻译扫描发现。
- 浏览器确认：普通模糊标点效果不变；集合聚焦圆形显示本地语言名称；编辑栏改名、距离和旋转实时生效且刷新后保留。
- 前端版本四处同步递增；运行全部 Node 测试、语法检查、差异空白检查；本地预览可访问；只提交本任务代码与文档，不提交用户数据改动，不推送。
